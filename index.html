Linguagens FrontEnd

Linguagem de marcação HTML 5 🔝

É linguagem de marcação

O HTML5 (HyperText Markup Language 5) é a versão moderna da linguagem de marcação utilizada para estruturar páginas e aplicações web. Seu objetivo é tornar o código mais semântico, acessível e compatível com aplicações modernas, eliminando a necessidade de diversos plugins externos.

Linguagem de estilo CSS4 🔝

É linguagem de estilo

O CSS (Cascading Style Sheets) define toda a aparência da aplicação.Controla:

  • cores
  • fontes
  • layouts
  • animações
  • responsividade
  • temas

Desde o CSS3, os recursos são publicados como módulos independentes, e não como uma versão única denominada "CSS4".

Linguagem de programação JavaScript ES2026 🔝

É linguagem de programação

O JavaScript é a linguagem responsável pela lógica das aplicações web. Com ele é possível:

  • manipular o HTML
  • consumir APIs
  • validar formulários
  • criar aplicações SPA
  • desenvolver aplicações Full Stack

O ECMAScript recebe uma nova edição todos os anos, incorporando recursos que já passaram pelo processo de padronização do TC39.
