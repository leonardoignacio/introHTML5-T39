CSS (Cascading Style Sheets)

O CSS (Cascading Style Sheets) define toda a aparência da aplicação.Controla:

  • cores
  • fontes
  • layouts
  • animações
  • responsividade
  • temas

Desde o CSS3, os recursos são publicados como módulos independentes, e não como uma versão única denominada "CSS4". Saiba mais...

Principais Conceitos e Novidades

Módulos de Seletores de Nível 4 (Selectors Level 4) e outras melhorias divididas por módulos.

  • Seletores de Nível 4: Introdução de novas formas avançadas de buscar elementos no HTML sem precisar inflar o código com tantas classes ou IDs.
  • Seletor de Pai (:has()): Permite estilizar um elemento pai com base no que ele contém (por exemplo, selecionar uma div apenas se ela tiver um img dentro).
  • Pseudo-classe :is() e :where(): Simplificam e agrupam listas longas de seletores, reduzindo a repetição e controlando a especificidade do código.
  • Pseudo-classe :not() aprimorado: Agora aceita uma lista complexa de seletores em vez de apenas um único seletor simples.
  • Divisão por Módulos: O CSS deixou de ser lançado em "pacotes únicos" (como CSS1, CSS2, CSS3) e passou a ser atualizado de forma modular pela W3C, onde cada parte evolui no seu próprio nível.
