HTML5 (HyperText Markup Language 5)

Linguagem de marcação HTML 5 🔝

É linguagem de marcação

O HTML5 (HyperText Markup Language 5) é a versão moderna da linguagem de marcação utilizada para estruturar páginas e aplicações web. Seu objetivo é tornar o código mais semântico, acessível e compatível com aplicações modernas, eliminando a necessidade de diversos plugins externos. O HTML5 é a quinta iteração do HTML e é a versão atual. Ele introduz novos recursos, focados, principalmente, em aprimorar a semântica da web. O HTML forma a base para o desenvolvimento de páginas da web e sistemas web. Ele possibilita a delimitação de diferentes partes de uma página da web, como cabeçalhos, rodapés, menus, listas, parágrafos, imagens, botões e muito mais. No entanto, o HTML não lida com o posicionamento de elementos; o CSS é usado para esse fim.

Estrutura Básica

  • <HTML>:O elemento raiz que envolve todo o documento.
  • <head>:Guarda as informações de configuração e metadados da página.
  • <title>:Define o título exibido na aba do navegador.
  • <body>:Contém todo o conteúdo visível para o usuário.
  • <h1> a <h6>:Títulos e subtítulos, do mais importante ao menor.
  • <p>: Define um parágrafo de texto.
  • <a>:Cria links para outras páginas ou arquivos.
  • <img>:Insere imagens na página.
  • <ul>, <ol>, <li>:Criam listas ordenadas e não ordenadas

Tags Semânticas do HTML5

  • <nav>:A área de navegação com menus e links principais.
  • <main>:O conteúdo central e principal do documento.
  • <section>:Uma seção genérica de conteúdo temático.
  • <article>:Um conteúdo independente, como um post de blog ou notícia.
  • <aside>:Conteúdo lateral, como barras com links secundários ou propagandas.
  • <footer>:O rodapé da página ou de uma seção.
